Política de Privacidade — FitCoach Pro

Última atualização: [data]

1. Quem somos

O FitCoach Pro é um aplicativo para personal trainers gerenciarem seus alunos, treinos, agenda e pagamentos. É operado por [nome/CNPJ do responsável pelo app]. Contato: [e-mail de contato].

2. Quem é o titular dos dados

O FitCoach Pro tem apenas um tipo de usuário com conta e login: o personal trainer. Os alunos não criam conta, não fazem login e não acessam o aplicativo. Os dados de alunos são inseridos e mantidos pelo próprio personal, como parte da gestão do seu negócio.

Sob a LGPD: o personal trainer é o controlador dos dados dos seus alunos; o FitCoach Pro atua como operador, processando esses dados sob as instruções do personal. Alunos que queiram exercer direitos sobre seus dados devem procurar primeiro o seu personal trainer.

3. Dados que coletamos

Do personal trainer (titular direto): nome completo, CPF, CREF, e-mail, WhatsApp/telefone, cidade, estado, data de nascimento, foto de perfil.

Dos alunos (inseridos pelo personal): nome, WhatsApp, e-mail, data de nascimento, gênero.

Dados de saúde (categoria sensível): peso, altura, objetivo, lesões, restrições físicas, observações de saúde, anamnese, avaliações físicas, fotos de evolução (quando essa função existir no app).

Dados financeiros: valor de mensalidade, datas de vencimento/pagamento, status e forma de pagamento.

4. Uso de inteligência artificial

Usamos uma função de servidor para gerar sugestões automáticas ("Insights de IA") sobre um aluno, a pedido do personal. Para isso, um subconjunto dos dados do aluno é enviado a um provedor externo de IA (Anthropic, API Claude) no momento da solicitação — não continuamente. Os dados enviados não incluem CPF, e-mail ou WhatsApp do aluno.

5. Com quem compartilhamos dados

Supabase (hospedagem de banco de dados, autenticação e arquivos) e Anthropic (processamento pontual de insights). Não vendemos dados a terceiros nem usamos para publicidade.

6. Retenção e exclusão de conta

Ao solicitar o encerramento da conta, há um período de carência de 30 dias em que a conta continua ativa e o pedido pode ser cancelado. Após o prazo: dados identificadores são anonimizados; fichas de saúde detalhadas e fotos são apagadas; registros financeiros são mantidos de forma anonimizada pelo tempo exigido pela legislação aplicável.

7. Seus direitos (LGPD)

Confirmação de tratamento, acesso, correção, anonimização/exclusão, portabilidade e informação sobre compartilhamento. Personal trainers podem exercer esses direitos pelo próprio app (Configurações → Excluir conta) ou pelo contato acima.
